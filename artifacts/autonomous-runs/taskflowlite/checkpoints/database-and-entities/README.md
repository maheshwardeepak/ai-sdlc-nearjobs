# TaskFlowLite

Lightweight task workflow application for small teams.

## Stack
- **Backend:** Spring Boot 3.2 (Java 17, Maven)
- **Frontend:** React 18 + TypeScript + Vite (pnpm)
- **Database:** PostgreSQL 15
- **Auth:** JWT + BCrypt
- **Migrations:** Flyway
